Описание JSON для POST-запроса

127.0.0.1:8000/generate

Поле Тип данных Описание Значение по умолчанию
request string Текст запроса. —
length integer Максимальная длина ответа. null
language string Требуемый язык ответа. null
model string Название модели. null
tries integer Количество попыток генерации. 3
timeout integer Время выполнения запроса (в секундах). 30
proxy boolean Принудительное использование прокси. false

Пример JSON

{
    "request": "Пример запроса",
    "length": 250,
    "language": "ru",
    "model": "gpt-4o",
    "tries": 3,
    "timeout": 30,
    "proxy": false
}
